# 高空世界空间鸟粒子 V1

## 定位

高空鸟只承担远景氛围。它们是纯客户端轻量对象，不注册实体，也不使用面向相机的 Billboard。鸟群拥有自己的世界坐标、航向、速度和侧倾，相机只影响透视和距离淡出。

七张贴图均为 `128 x 32` 透明 PNG，横向包含四个 `32 x 32` 仰视飞行帧。贴图采用硬像素边缘、透明安全边距和最近邻采样；清晰度符合原版 MC 的粗像素画风，同时避免旧版半透明边缘造成的模糊：

1. 平展滑翔；
2. 开始下拍；
3. 最低下拍；
4. 回升上拍。

图集的每帧保留透明安全边距，UV 向内缩进半个像素，避免相邻帧的翅膀、头尾串入当前画面。纹理强制使用最近邻采样并关闭 mipmap，望远镜放大时仍保持清晰的像素边缘。

大雁循环播放四帧。鹰以第一帧滑翔为主，只在随机间隔播放一轮上拍、下拍和回升。
海鸥同样以滑翔为主，但拍翼比鹰频繁，并让同群成员使用不同相位。
燕子会连续快速拍翼数轮，再进入一次很短的展翼滑翔。
鹤类使用缓慢而接近同步的群体扑翼，但保留少量个体相位差。
秃鹫几乎一直保持展翼滑翔，只在很长的随机间隔后补拍一轮。
椋鸟会快速拍翼数轮并短暂滑翔，各成员使用不同动画相位。

## 渲染

每只鸟绘制为世界空间中的水平薄片。薄片的纵轴跟随 `forward`，横轴跟随 `right`，侧倾时绕飞行方向旋转。玩家转动视角不会改变鸟的平面朝向或贴图方向。

鸟从接近侧面的位置观察时会自然变薄，这是世界空间薄片的预期表现。高空玩家靠近时使用距离淡出，不转换成实体。

## 行为

- 大雁群在玩家周围的随机方位生成；
- 航向独立随机，不追随玩家视线；
- 使用稳定的 V 字队形和轻微个体高度差；
- 每只鸟拥有可复现的扑翼相位、尺寸和侧倾偏移；
- 鹰以单只形式出现，围绕生成时确定的世界坐标做大半径盘旋；
- 鹰多数时间展翼滑翔，盘旋时保持压翼，并在随机时机补拍一次；
- 海鸥只在 `seagull_habitat` 中自然触发，也就是海滩、河流和海洋群系；
- 海鸥以 3～6 只松散结伴，沿宽缓 S 形路线滑翔，并带轻微的个体升降和错位；
- 燕子以 4～9 只组成不规则流线小群，在平原、草甸、河流和常见林地边缘快速掠过；
- 燕子使用复合弧线转向、短周期升降和独立局部航向，动作比其他高空鸟更敏捷；
- 鹤类以 3～6 只迁飞，随机采用浅 V 队或单侧斜列队，长颈和双腿始终伸展；
- 鹤类主要出现在河流、沼泽、红树林沼泽和平原上空，航向与高度变化都较缓慢；
- 秃鹫以 1～2 只形成松散的高空盘升群，热气流圆心随风缓慢漂移，半径和高度持续轻微变化；
- 秃鹫只在沙漠、恶地、稀树草原、风袭丘陵和石峰等干旱或山地环境自然出现；
- 椋鸟以 10～18 只形成动态群阵，在团状、横向带状和波浪状之间连续变化；
- 椋鸟群会偶尔平滑分成两股再汇合，每只鸟根据自己的局部位移调整航向；
- 椋鸟主要出现在平原、草甸、稀树草原和林地边缘，黄昏触发概率显著提高；
- 大雁使用 `goose_sky_habitat`，覆盖平原、草甸、雪原、湿地、河流、海岸和海洋；
- 鹰使用 `eagle_sky_habitat`，覆盖风袭丘陵、山峰、针叶林、恶地和高原；
- 雷暴不生成，雨天按鸟种降低权重；海鸥受雨影响最小，猛禽受影响最大；
- 清晨和黄昏提高迁飞鸟权重，中午提高鹰和秃鹫等热气流滑翔鸟权重，黄昏显著提高椋鸟权重；
- 每 5 秒重新读取玩家当前群系、时间、天气和可用贴图。玩家跨群系或天气变化后，不符合新环境的旧鸟群会在 2～4 秒内淡出；
- 每 45～75 秒刷新一次天空场景。鸟群满额时会让最老的自然鸟群淡出，为当前生态中的新群留出位置；
- 自然生成按当前生态池加权抽取，并降低连续重复同一种鸟的概率；
- 自然鸟群每 10～20 秒尝试生成一次；天空为空时成功率会适度提高，已有鸟群时会主动降低；
- 最多同时存在两群，通常只维持一群，同一鸟种还受各自的群数上限控制。

## 群系生态池

| 环境 | 主要天空鸟 |
| --- | --- |
| 海岸、海洋、河流 | 海鸥、大雁；湿地区域还可出现鹤 |
| 平原、草甸、林地边缘 | 燕子、椋鸟；部分区域可见大雁或鹤迁飞 |
| 山地、风袭丘陵、针叶林、高原 | 鹰 |
| 沙漠、恶地、稀树草原、石峰 | 秃鹫；高地也可能出现鹰 |
| 沼泽、红树林沼泽 | 鹤与大雁 |

## 调试指令

- `/skybird spawn`：在准星前上方生成 12 只测试大雁；
- `/skybird spawn <count>`：生成 1～32 只；
- `/skybird spawn goose [count]`：明确生成测试大雁群；
- `/skybird spawn eagle`：在准星前上方生成一只盘旋测试鹰；
- `/skybird spawn seagull [count]`：生成 1～16 只松散飞行的测试海鸥；
- `/skybird spawn swallow [count]`：生成 1～20 只快速掠过的测试燕子；
- `/skybird spawn crane [count]`：生成 1～12 只缓慢迁飞的测试鹤；
- `/skybird spawn vulture [count]`：生成 1～6 只利用热气流盘升的测试秃鹫；
- `/skybird spawn starling [count]`：生成 1～32 只动态变阵的测试椋鸟；
- `/skybird status`：查看贴图、当前群系生态池、鸟群、鸟数和上一帧绘制数；
- `/skybird refresh`：立即按当前群系、时间和天气重新计算生态池；
- `/skybird clear`：清除当前客户端鸟群。
